# Python from zero to local problem solving

## Audience and duration

This one-day workshop is for adults with little or no previous programming experience. It has seven hours of instruction and hands-on work, excluding registration, breaks, and lunch.

## Learning outcomes

By the end of the workshop, participants will be able to:

1. Run and modify a basic Python program.
2. Use variables, common data types, input/output, operators, and conditionals.
3. Use loops, lists, dictionaries, and simple functions.
4. Read a small CSV file and calculate a basic summary.
5. Read common error messages and make a first debugging attempt.
6. Build and explain a small solution to a local, personal, educational, or professional problem.

## Teaching sequence

### 1. First program

Start from a working `print()` example. Participants change a message and explain what changed. Introduce variables as named values that make a program easier to read and change.

### 2. Decisions

Use comparisons and `if` / `elif` / `else` to classify simple cases. Emphasize testing more than one input, including an edge case.

### 3. Repetition and collections

Use a `for` loop to process a list. Introduce dictionaries as named facts and distinguish them from lists.

### 4. Functions

Extract a repeated rule into a function with clear parameters and a return value. Ask participants to use descriptive names and test the function with at least two cases.

### 5. Data activity

Read the fictional transaction file with Python's `csv` module. Calculate a total and a count by category. Discuss why data must be checked before drawing conclusions.

### 6. Guided project

In small groups or individually, participants select a small context and build a program that includes a conditional, a loop, a function, and a collection. The program may use fictional or public data only.

## Assessment

The facilitator uses the project rubric and a brief before/after check of the concepts above. Results are reviewed in aggregate; individual results are not published.
