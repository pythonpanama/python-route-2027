# Guided project rubric

Each criterion is rated from 1 (starting) to 4 (achieved).

| Criterion | 4 — Achieved | 3 — Adequate | 2 — Partial | 1 — Starting |
|---|---|---|---|---|
| Functionality | Solves the stated problem and handles more than one case | Solves the main case | Runs with important gaps | Does not run yet |
| Python concepts | Uses a conditional, loop, function, and collection appropriately | Uses three of the four elements | Uses two elements | Uses zero or one element |
| Clarity | Names and structure are easy to follow | Mostly readable | Hard to follow in places | Difficult to read |
| Testing | Tests several cases and explains a result | Tests the main case | Test is incomplete | No visible test |
| Explanation | Explains choices and a next learning step | Explains how it works | Explanation is partial | Cannot yet explain the program |

The rubric supports feedback and aggregate learning evaluation. Do not publish individual scores or participant names.
