# Python Route 2027 — materials

Open teaching materials for **Python Route 2027**, a beginner-friendly, one-day Python workshop organized by Python Panamá.

The same seven-hour workshop will be delivered in David, Santiago, and La Chorrera. Dates and venues are being confirmed with the local host institution; they are not announced in this repository.

## What is here

- [`curriculum/one-day-workshop.md`](curriculum/one-day-workshop.md): learning outcomes, agenda, and teaching sequence.
- [`exercises/`](exercises): starter exercises for the workshop.
- [`data/transactions.csv`](data/transactions.csv): fictional practice data for the data activity.
- [`facilitator/project-rubric.md`](facilitator/project-rubric.md): rubric used for the final guided project.

## Before the workshop

Participants need Python 3.11 or later and a code editor. The exercises use only the Python standard library. They can also be run in Google Colab after uploading the CSV file for Exercise 5.

Do not add participant names, contact details, assessment responses, or photos to this repository.
